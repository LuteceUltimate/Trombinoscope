# Photos

Une image par personne, nommée d'après la colonne `photo` du tableur.

- **Convention** : `prenom-nom.jpg`, sans accent ni majuscule
  (`Jean-Loup Quéméner` → `jean-loup-quemener.jpg`).
- **Format** : carré, 400 × 400 px suffit, JPEG ou WebP, moins de 100 Ko.
- **Facultatif** : une case `photo` vide affiche les initiales sur la couleur
  du pôle principal. Ce n'est pas un pis-aller, c'est l'état par défaut assumé.
  Une photo manquante ne doit jamais faire un trou dans la grille.
- Si le fichier est introuvable, la page retombe seule sur les initiales.

Aucune photo n'est versionnée tant que le site est publié sur GitHub Pages.
